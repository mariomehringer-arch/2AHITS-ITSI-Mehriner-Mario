# Übung 2

1.Binäre Ausgabe
echo -n "A" | xxd -b
echo -n "A" | hexdump -b

2.Octet

Ein Octet sind immer 8 Bit. Der Begriff wird verwendet, weil ein Byte früher nicht auf allen Systemen 8 Bit hatte.

3.xxd -E

Zeigt die Zeichen als EBCDIC statt ASCII an.

4.Was macht das?

value=65534
printf "%.8x" $value | xxd -r -p > data.bin

%.8x wandelt die Zahl in eine 8-stellige Hexzahl um.

xxd -r -p macht daraus echte Binärdaten.

Die 4 Bytes werden in data.bin gespeichert.

5. Wieder als Dezimalzahl anzeigen

od -An -N4 -tu4 --endian=big data.bin

Ergebnis: 65534

5.xxd -i
xxd -i data.bin

Wandelt eine Datei in ein C-Array um. Nützlich, um Dateien direkt in C-Programme einzubauen.

# Übung 3

Bei cat wird die UTF-8 Datei korrekt angezeigt. Die ANSI-Datei zeigt oft falsche Zeichen, weil die REPL standardmäßig UTF-8 verwendet.

UTF-8:
Ö = C3 96
ß = C3 9F
€ = E2 82 AC

ANSI (CP-1252):
Ö = D6
ß = DF
€ = 80

Windows-Zeilenumbruch: 0D 0A (CRLF)
Linux-Zeilenumbruch: 0A (LF)

ANSI nach UTF-8 konvertieren:

iconv -f CP1252 -t UTF-8 ansi.txt > utf8.txt

Unterschied ANSI und Latin-1:
Latin-1 ist ein Standard. ANSI (CP-1252) basiert darauf, enthält aber zusätzliche Zeichen wie das Euro-Zeichen (€). Deshalb sind sie ähnlich, aber nicht gleich.
