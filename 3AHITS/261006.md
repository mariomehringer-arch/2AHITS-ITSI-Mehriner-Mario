## 4 Tastatur einstellen auf Deutsch und VsCode in Kali Linux installieren

### Metaspoitable

```sh
sudo loadkeys de
```

### Kali
```sh
setxkbmap de
wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"
sudo apt install ./vscode.deb
```
